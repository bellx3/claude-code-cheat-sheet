🖥️ Claude Desktop 치트시트 — Code 탭 실무자용 (CLI 미포함) (A4)

다운로드부터 권한 모드·워크스페이스·Computer Use·엔터프라이즈 관리까지, 공식 문서 기준 정리
공식 문서 웹 조사 기준 최종 확인: 2026-08-12
출력 권장: A4 가로, 여백 최소, 배경 그래픽 인쇄 켜기

🟣 다운로드 & 시작

  • macOS: 유니버설 dmg / Windows: x64(ARM64 별도) / Linux(베타): apt·deb
  • 설치 후 로그인 → Code 탭 클릭
⚠️ Windows는 Git for Windows 필요(설치 후 재시작)

🟣 세 가지 탭

Chat일반 대화
CoworkDispatch·장기 에이전틱 작업
Code소프트웨어 개발 (이 치트시트 범위)

🟣 세션 시작 설정 (4가지)

EnvironmentLocal/Cloud/SSH/WSL(Win) 선택
Project folder작업할 폴더·저장소 선택
Model전송 버튼 옆 드롭다운(세션 중 변경)
Permission mode모드 선택기(세션 중 변경)

🔐 권한 모드

Manual (default)편집·명령 전 항상 확인
Accept edits파일편집+기본 명령 자동승인
Plan탐색만, 편집 전 계획 제시
Auto안전검사로 대부분 자동
Bypass permissions프롬프트 없음, 격리 전용
⚠️ Bypass: Pro/Max 설정 토글, Team/Ent.는 조직정책. dontAsk는 CLI 전용

🖊 프롬프트 박스

  • Enter 전송, 진행 중 정정 메시지도 중단 없이 반영
  • @파일명 컨텍스트 추가(로컬·SSH만) · 이미지/PDF 드래그첨부
  • + 버튼: 파일첨부/스킬/커넥터/플러그인

⌨ 슬래시 명령어

/ 입력 또는 +→Slash commands 로 탐색 (내장 명령어 + 커스텀·프로젝트·플러그인 스킬)
/clear, /compact, /context새 대화/요약/컨텍스트 확인
/rewind, /diff체크포인트 롤백/diff 뷰어
/model, /effort, /plan모델·강도 변경/계획 모드
/rename, /branch, /export이름변경/분기/내보내기
/code-review, /security-reviewdiff·보안 검토
/background, /tasks, /fork백그라운드 분리/작업목록/복사
/loop, /goal, /recap반복/목표설정/요약
/btw, /desktop, /ide, /mcp사이드챗/CLI→데스크톱 이동/연동
⚠️ /permissions 등 터미널 전용 대화형 명령어는 "isn't available in this environment" 응답. /config 는 인자 무시하고 설정 화면만 열림

🖥 앱 미리보기 (Browser pane)

  • 수정 후 자동으로 dev 서버 실행·검증(스크린샷/DOM검사/클릭/폼입력)
  • 서버 드롭다운에서 시작/중지
  • Persist sessions: 재시작해도 쿠키·로컬스토리지 유지

🌐 외부 사이트 브라우징

  • Cmd/Ctrl+Shift+B 로 Browser pane 열기
  • 첫 접근 시 승인 카드(Allow once/Always allow/Deny), 사이트별 개별 승인
  • 로그인 상태 공유 필요시 Claude in Chrome 확장 사용 (Browser pane은 별도 프로필)

📝 Diff 리뷰 & 코드 리뷰

  • diff stats(+12 -1) 클릭 → diff 뷰어에서 파일별 검토
  • 줄 클릭해 댓글, Cmd/Ctrl+Enter로 한번에 제출
  • Review code: 컴파일오류·버그·보안 위주 자동 리뷰(스타일 제외)

🔀 PR 모니터링

  • PR 생성 후 CI 상태 바 표시 (GitHub CLI gh 필요)
  • Auto-fix: 실패한 체크 자동 수정 / Auto-merge: 통과 시 squash 병합
  • 완료 시 데스크톱 알림

🧩 워크스페이스 배치

패널: chat·diff·browser·terminal·file·plan·tasks·subagent(+macOS iOS시뮬레이터)
헤더 드래그 이동, Cmd/Ctrl+\ 포커스 패널 닫기

💻 터미널 & 파일 편집기

  • Ctrl+` 통합 터미널(로컬 세션 전용, 세션과 환경 공유)
  • 파일 클릭→편집·저장, 우클릭→다른 앱/탐색기/경로복사

👁 뷰 모드

Normal도구호출 요약+전체 응답
Verbose모든 도구호출·중간단계
Summary최종 응답·변경사항만
Ctrl+O 순환 전환

📊 사용량 확인

모델 선택기 옆 사용량 링 클릭 → 컨텍스트 사용량(세션별) + 플랜 사용량(전체 서피스 공유)

🖱 Computer Use

  • 화면·앱 직접 조작(CLI 없는 GUI 자동화), macOS/Win Pro·Max 프리뷰(Team/Ent 불가)
  • 기본 꺼짐: 설정→Computer use 토글(macOS는 손쉬운사용+화면기록 권한 추가)
  • View only/Click only/Full control 3단계, 세션당 1회 승인

🗂 세션 관리

  • Cmd/Ctrl+N 새 세션, 병렬 실행, 세션마다 자동 Git worktree 격리
  • Cmd/Ctrl+클릭으로 2개 세션 분할 보기
  • 완료 후 보관 아이콘, PR 병합 시 자동 보관 설정 가능

💬 사이드 채팅

Cmd/Ctrl+; 또는 /btw 로 열기 — 메인 세션 컨텍스트는 읽지만 기록엔 안 남음(로컬·SSH·WSL만)

📋 백그라운드 & 세션 간 작업

  • Tasks 패널: 서브에이전트·백그라운드 셸·워크플로우
  • 자연어로 다른 세션 확인/메시지/보관 요청(최근 20개, 클라우드 제외)

☁ 클라우드 세션 & 이어가기

  • Cloud 선택 → 앱 종료해도 계속 실행, claude.ai/code·모바일 앱에서 확인
  • 여러 저장소 동시 추가 가능
  • Continue in: 웹 세션 전송 또는 IDE로 열기

📱 Dispatch (Cowork 탭)

  • 폰에서 작업 지시 → 개발 작업이면 자동으로 Code 세션 생성(Dispatch 배지)
  • 완료·승인 필요 시 푸시 알림, Pro/Max 전용(Team/Enterprise 불가)

🔌 커넥터 연결

+ 버튼 → Connectors: Google Calendar/Slack/GitHub/Linear/Notion 등(로컬·SSH만, 클라우드·WSL 불가)
설정→Connectors 에서 관리·연결 해제

🧰 스킬 & 플러그인

  • +→Slash commands: 내장 명령어·커스텀 스킬·플러그인 스킬 탐색
  • +→Plugins: 설치 확인, "Add plugin"으로 마켓플레이스 설치
  • 플러그인은 클라우드·WSL 세션에서는 사용 불가

⚙ 프리뷰 서버 (.claude/launch.json)

name/runtimeExecutable식별자/실행 명령
runtimeArgs/port(3000)인자/포트
cwd/env/autoPort경로/환경변수/포트 자동할당
program/urlnode 직접 실행/접속 주소
autoVerify 기본 켜짐(수정마다 자동 검증)

🖧 환경 종류

Local내 컴퓨터에서 직접 실행
CloudAnthropic 관리 인프라
SSH원격 머신(Linux·macOS만)
WSL(Windows)WSL2 배포판 내 실행

🏢 엔터프라이즈 관리

  • 관리 콘솔: Code 데스크톱 사용여부, 웹 세션, Remote Control, Bypass 모드 비활성화 등 제어
  • Managed settings: disableAutoMode, sshHostAllowlist, managedMcpServers 등
  • macOS는 MDM(Jamf/Kandji), Windows는 그룹 정책/레지스트리로 관리

🔒 네트워크 & 데이터 처리

허용 도메인: anthropic.com, claude.ai, claude.com, claude.app, *.claudeusercontent.com (HTTPS 443)
로컬 세션은 로컬 처리, 클라우드 세션은 Anthropic 관리 인프라에서 처리

📊 CLI → 데스크톱 대응표

--model모델 드롭다운
--resume/--continue사이드바 세션 클릭
--permission-mode모드 선택기
--dangerously-skip-permissionsBypass permissions 모드
--add-dir클라우드 세션 + 버튼
--allowedTools 등대응 없음(설정파일만 적용)
--verboseVerbose 뷰 모드
--print/--output-format미지원(대화형 전용)

📋 기능 비교: CLI vs 데스크톱

권한 모드CLI 전체(dontAsk포함) / 데스크톱 4종+Bypass
MCP·플러그인CLI는 설정파일·명령 / 데스크톱은 UI
파일 첨부CLI 불가 / 데스크톱 이미지·PDF 가능
세션 격리CLI --worktree / 데스크톱 자동
반복 작업CLI cron/CI / 데스크톱 Scheduled tasks
Dispatch/스크립팅데스크톱만/CLI만 지원

🔗 CLI와 공유되는 설정

  • CLAUDE.md, CLAUDE.local.md — 둘 다 사용
  • MCP 서버, Hooks, Skills, ~/.claude/settings.json — 모두 공유
  • 터미널에서 /desktop 입력 → 현재 세션을 데스크톱 앱으로 이동

💡 데스크톱 vs CLI, 언제 무엇을

병렬 세션 관리, 패널 배치, 변경사항 시각적 검토 → 데스크톱
스크립팅, 자동화, 터미널 워크플로우 선호 → CLI

🛠 트러블슈팅

  • 403/인증 오류 → 재로그인, 구독 확인
  • 화면 멈춤 → 재시작, 업데이트, 방화벽 CDN 확인
  • "Failed to load session" → 폴더/Git LFS 확인
  • Windows Git 필요 → Git for Windows 설치 후 재시작

내장 슬래시 명령어 전체 + 플러그인 설치 문법 + 가장 많이 쓰는 플러그인 5선, 공식 문서 기준

🧩 플러그인 명령어 문법

/plugin   # Discover/Installed/Marketplaces/Errors

/plugin marketplace add owner/repo | url | 경로
/plugin marketplace list / update <name> / remove <name>

/plugin install <name>@<marketplace>
/plugin uninstall / enable / disable <name>@<marketplace>
/plugin list [--enabled|--disabled]

/reload-plugins [--force]   # 변경사항 즉시 적용

📦 플러그인 스코프 & 관리

User내 계정, 모든 프로젝트
Projectsettings.json 기록, 공유
Local이 저장소에서 나만
스킬은 plugin-name:command 형태 (예: /commit-commands:commit)
⚠️ "Run /reload-plugins to activate." 표시되면 반드시 실행

⭐ 가장 많이 쓰는 플러그인 TOP 5

1. Frontend Design(공식) — 디자인 품질 향상, 설치 1위
/plugin install frontend-design@claude-plugins-official
2. Superpowers — 개발 워크플로우 모음
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace
3. Context7 — 최신 라이브러리 문서 조회
/plugin marketplace add upstash/context7
/plugin install context7@context7-marketplace
4. Claude Mem — 세션 간 영구 메모리
npx claude-mem install(별도 설치)
5. Caveman — 토큰 절약 축약 모드
/plugin marketplace add JuliusBrussee/caveman
/plugin install caveman@caveman

💡 플러그인 실무 팁

  • 설치 전 출처 신뢰도 확인(Anthropic 미검증)
  • Context cost로 토큰 비용 확인 후 설치
  • 미사용 플러그인은 Installed 탭에서 정리
  • claude plugin install <name>@<mp> --scope project

🧭 언제 슬래시 vs 플러그인

내장 명령어 → Claude Code 자체 기능 제어
플러그인 → 스킬·에이전트·MCP·Hooks 패키지 확장

🛠 커스텀 슬래시 명령어 만들기

.claude/commands/*.md 에 정의
  • frontmatter: name, description, aliases
  • 본문에 $ARGUMENTS 로 인자 전달
  • 예: .claude/commands/deploy.md → /deploy

🎯 실전 조합 예시

  • 기능 개발: /plan → 구현 → /code-review → /security-review
  • 디버깅: /rewind 로 되돌린 뒤 재시도
  • PR 마무리: /diff 검토 → 커밋 → /release-notes

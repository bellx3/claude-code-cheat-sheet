🟣 자동화 & 스크립팅

#!/bin/bash
claude -p "analyze codebase" \
  --output-format json > analysis.json

SESSION_ID=$(claude -p "start" \
  --output-format json | jq -r '.session_id')
claude -r "$SESSION_ID" "continue"

claude -p "step1" | claude -p "step2" | claude -p "step3"

⚫ CI/CD·Git·서드파티 연동

git diff HEAD~1 | claude -p "보안 이슈 리뷰" > review.md
claude -p "테스트 커버리지 분석" --output-format json | jq '.coverage_percentage'
find . -name "*.js" -exec claude -p "버그 분석: {}" \; > bugs.txt
docker logs container | claude -p "에러 찾아줘"
mysql -e "SHOW TABLES" | claude -p "DB 구조 분석"

⚪ 성능 최적화

  • /clear 작업 사이마다 자주 사용
  • --max-turns로 컨텍스트 제한
  • /compact "핵심만 유지"
  • claude -p "t1" & claude -p "t2" & wait 병렬 실행
  • /doctor --performance 성능 진단

🔘 엔터프라이즈

claude --production-mode --security-enabled \
  --audit-logging --max-turns 10 "분석"

claude --disallowedTools "Bash(rm:*)" "Bash(sudo:*)" \
  "Bash(chmod:*)" --audit-mode --no-external-calls

claude --audit-log /var/log/claude-audit.log "점검"

💡 실무 모범 사례

성능

  • 작업 전환마다 /clear
  • --max-turns로 폭주 방지
  • 장기 대화는 /compact

보안

  • --dangerously-skip-permissions 지양
  • 위험 명령은 --disallowedTools로 항상 차단
  • 도구 권한 주기적 점검, 최신 버전 유지

워크플로우

  • 반복 작업 → .claude/commands/ 커스텀 명령어화
  • 자동화 → --output-format json
  • 장시간 작업 → 세션 ID 활용

🧭 레벨별 학습 가이드

초급 (Lv1-3)

기본 명령어 → /help 자주 활용 → 작업 간 /clear

중급 (Lv4-6)

도구 권한 마스터 → JSON 출력 자동화 → MCP 연동 → 커스텀 명령어

고급 (Lv7-10)

CI/CD 자동화 → 팀 협업 기능 → 성능 모니터링 → 프로덕션 보안 정책

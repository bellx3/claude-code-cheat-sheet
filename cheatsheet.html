💡 실무 모범 사례 — 성능·보안

  • 작업 전환마다 /clear로 컨텍스트 초기화
  • --max-turns로 무한 반복 방지
  • 장기 대화는 /compact로 압축
  • --dangerously-skip-permissions 사용 지양
  • 위험 명령은 --disallowedTools로 상시 차단
  • 도구 권한 주기적 점검, 항상 최신 버전 유지

💡 실무 모범 사례 — 워크플로우

  • 반복 작업 → .claude/commands/ 커스텀 명령어화
  • 자동화 스크립트 → --output-format json
  • 복합 작업 → 파이프로 단계별 연결
  • 장시간 작업 → 세션 ID로 관리, 에러 처리 구현
  • 팀 공유용 워크플로우는 문서화

🧭 레벨별 학습 가이드

초급 (Lv1-3)

기본 명령어부터 → /help 자주 활용 → 간단한 질의로 연습 → 작업 간 /clear

중급 (Lv4-6)

도구 권한 마스터 → JSON 출력 자동화 → MCP 연동 학습 → 반복 작업은 커스텀 명령어화

고급 (Lv7-10)

반복 워크플로우 자동화 → 팀 협업 기능 활용 → 성능·리소스 모니터링 → 프로덕션 보안 정책 준수

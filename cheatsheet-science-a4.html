설치부터 커넥터·스킬·HPC 연동·CLI·네트워크 정책까지, 공식 문서 기준 정리

출력 권장: A4 가로, 여백 최소, 배경 그래픽 인쇄 켜기

🔬 Claude Science란

Claude + 로컬 분석 환경을 결합한 데스크톱 앱. 자연어 요청 → Python/R/shell을 샌드박스에서 실행 → 출처 기록 포함 버전 관리 아티팩트로 저장
  • 파일은 내 컴퓨터에 유지, 코드는 샌드박스 실행
  • 새 폴더·네트워크 호스트·원격 잡은 매번 승인
  • 백그라운드 리뷰어가 주장과 실행 기록 대조
⚠️ 연구 도구 — 임상·진단 용도 아님. 결과는 직접 검증 필수

💻 시스템 요구사항

플랜Pro/Max/Team/Enterprise (Free 불가)
macOS13+ (Apple Silicon/Intel)
Linuxx64 glibc (arm64·Alpine 불가)
디스크약 5GB
Linux 필수socat, bubblewrap 0.8.0+, 비특권 네임스페이스
⚠️ 네이티브 Windows 빌드 없음 — WSL2 사용

📥 설치 (macOS / Linux)

macOS: claude.com/product/claude-science 에서 설치 파일 다운로드 → 더블클릭
# Linux 샌드박스 의존성 (sudo)
sudo apt-get install -y curl bubblewrap socat
bwrap --version   # 0.8.0+ (22.04 불가, 24.04 OK)

curl -fsSL https://claude.ai/install-claude-science.sh | bash
claude-science serve
⚠️ 브라우저 탭에서 열리지만 로컬 앱 — 공개 URL 없음, API 키 불필요

🪟 Windows (WSL2)

wsl --install -d Ubuntu-24.04   # 관리자 PS
wsl -l -v                        # 버전 2 확인

sudo apt install -y curl bubblewrap socat
curl -fsSL https://claude.ai/install-claude-science.sh | bash
. ~/.profile
claude-science serve --port 8765 --no-browser
⚠️ WSL 1 불가, Ubuntu 24.04+ 필요. wsl --shutdown 시 앱도 종료

✏️ 어노테이션

영역 선택 → Annotate pill → 코멘트 → Cmd/Ctrl+Enter
  • 저장만으론 전송 안 됨 — N comments chip에 모였다 다음 메시지와 함께 전송
  • 가능: Markdown, text, LaTeX, code, PDF(페이지), 이미지, 렌더된 HTML, transcript
  • 불가: 테이블 · 스레드/resolve 없음 · 1,000자 제한

🐍 실행 환경 & 패키지

persistent kernel에서 실행, 변수 유지. 30분 idle·패키지 설치·세션 종료 시 재시작
Starter env — Python: numpy, pandas, scipy, matplotlib, seaborn, pillow / R: tidyverse, ggplot2, jsonlite
설치 소스: micromamba(conda-forge, bioconda, pytorch) · pip/PyPI · CRAN·Bioconductor
  • 환경 설치=영구 / 셀 내 pip install=커널 재시작까지
  • GPU는 Linux만 — Settings > Compute에서 활성화
⚠️ apt·sudo·root 없음 — 없으면 소스 빌드

📦 아티팩트 & Provenance

  • 아티팩트는 영구, 그 외 세션 파일은 종료 후 삭제
  • 같은 파일명 재저장 = 새 버전 (version stepper + diff)
  • 인라인 편집: Markdown, code, text / 불가: 이미지, PDF, HTML, 테이블
Provenance 5탭: Messages · Code · Execution Log · Environment · Review
⚠️ Execution Log가 권위 있는 기록 — Code 탭과 불일치 시 로그 신뢰. ~/.claude-science 직접 수정 금지

🔍 리뷰어 (Reviewer)

응답·plan·아티팩트·실행 기록을 독립 재독해 주장과 대조 (재실행 안 함)
  • 실행 없이 계산했다고 보고한 결과
  • 응답 값과 원본 파일 불일치
  • 인용이 주장을 뒷받침 안 함 / DOI 오연결
  • 미완료 plan 단계 · 뒷받침 안 되는 결론
자동 + Request review 수동. 기본값 Max/Team/Ent ON, Pro OFF. 커스텀은 Settings > Specialists > Reviewer

⌨ CLI 서브커맨드

serve실행 + 1회용 로그인 링크
open / url링크 발급+열기 / 출력만(SSH용)
status실행 여부·버전·포트 JSON
logs [--tail]로그 출력 / 실시간

전역: --data-dir, --config
⚠️ import는 되돌리기 없음 — 사전 백업 필수

🚩 serve 플래그

--port <n>기본 8000 (0=자동)
--no-browser자동 오픈 안 함
--detached백그라운드
--host <addr>기본 127.0.0.1
--base-path리버스 프록시용
--sandbox-port기본 port+1 (미리보기)
--no-auto-update자동 업데이트 끄기
☠️ --dangerously-no-sandbox · --dangerously-skip-approvals

🖥 SSH / Slurm 클러스터

Settings > Compute > SSH hosts > Add SSH host
  • ~/.ssh/config alias 선택 (user·port·ProxyJump 자동)
  • 호스트 메모(partition, account, module load) — Claude가 읽음
  • 추가 시 read-only 프로브로 GPU·conda·scratch·sbatch 탐지
  • 실행: 워크스테이션=detached, SLURM=sbatch. 연결 끊겨도 유지
  • 기본 타임아웃 30분, 동시 잡 100. 100MB 초과 출력은 경로만 기록
⚠️ 원격 잡은 샌드박스 밖 — 내 계정 권한 전체로 실행

☁ Modal & 모델 엔드포인트

Settings > Compute > Cloud providers → Modal
modal token new   # ~/.modal.toml 자동 인식
  • 승인 카드에 스펙(H100)·초당 과금·최대 청구 표시
  • 입력 1 GiB/submit, 출력 ./out/ 최대 5 GiB
  • 동시 잡 10, 컨테이너 타임아웃 12h(최대 23)
Model endpoints: NVIDIA BioNeMo NIM + NGC API 자격증명 → 호스팅 API 또는 로컬 Docker NIM
⚠️ 지출 상한 없음 · 앱 종료해도 잡은 계속 과금

🗄 클라우드 스토리지

Settings > Credentials → AWS / Google Cloud / Azure
  • 버킷 등록 = 네트워크 허용목록 추가(호출별 카드 없음)
  • 코드에서 boto3·Azure SDK. Settings > Storage에서 탐색·임포트(최대 100GB)
⚠️ GCS는 HMAC key + boto3만 — gsutil·google-cloud-storage는 path-style이라 차단

🔌 커스텀 MCP 커넥터

Settings > Connectors > Add connector → Remote(HTTPS) 또는 Local command. Name은 소문자·숫자·하이픈
  • Remote: URL + transport(SSE/Streamable HTTP), OAuth
  • Local: 실행 명령 + 인자·환경변수
  • 툴 기본 Ask each time → Always allow/Block
⚠️ Local 환경변수는 암호화 없이 저장 — 고가치 시크릿 금지

📄 config.toml & 환경변수

~/.claude-science/config.toml — 시작 시 1회 읽음, 재시작 후 적용
[network]
proxy = "http://proxy.example.corp:8080"
no_proxy = ".example.corp"
ca_bundle = "/etc/claude-science/ca.pem"
mcp_x509_strict = "auto"  # relaxed|strict

[conda]
channel_mirror = "https://..."
pip_index_url  = "https://..."

[sandbox.network]
enabled = true
allowed_domains = ["*.example.org"]
denied_domains = []   # 거부 우선
환경변수: DO_NOT_TRACK(텔레메트리 끄기), GITHUB_TOKEN, HTTPS_PROXY/NO_PROXY(설정보다 우선)
⚠️ 미러 값 오류 시 앱이 시작 안 됨. 파일 값이 Settings보다 우선

🔒 데이터 취급 (local-first)

  • 대화·산출물은 내 기기에만(~/.claude-science) — Anthropic 세션 저장소 없음
  • Anthropic 수신: 프롬프트·응답 + 텔레메트리(대화 내용 아님, 끌 수 있음)
  • 원격 컴퓨트 트래픽은 Anthropic 경유 안 함
⚠️ 폴더 삭제 = 전부 영구 삭제. Custom Data Retention·Compliance API 미적용 → MDM/EDR 관리

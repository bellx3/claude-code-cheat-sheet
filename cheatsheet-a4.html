💡 실무 모범 사례 — 성능·보안

  • 작업 전환마다 /clear로 컨텍스트 초기화
  • --max-turns로 무한 반복 방지
  • 장기 대화는 /compact로 압축
  • --dangerously-skip-permissions 사용 지양
  • 위험 명령은 --disallowedTools로 상시 차단
  • 도구 권한 주기적 점검, 항상 최신 버전 유지

💡 실무 모범 사례 — 워크플로우

  • 반복 작업 → .claude/commands/ 커스텀 명령어화
  • 자동화 스크립트 → --output-format json
  • 복합 작업 → 파이프로 단계별 연결
  • 장시간 작업 → 세션 ID로 관리, 에러 처리 구현
  • 팀 공유용 워크플로우는 문서화

🧭 레벨별 학습 가이드

초급: 기본 명령어 → /help → 작업 간 /clear
중급: 도구 권한 → JSON 자동화 → MCP → 커스텀 명령어
고급: CI/CD 자동화 → 팀 협업 → 성능 모니터링 → 보안 정책

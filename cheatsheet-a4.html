🟠 도구 & 권한

--allowedTools "Bash(git log:*)" "Write"
--disallowedTools "Bash(rm:*)" "Bash(sudo:*)"
--permission-prompt-tool mcp_auth_tool
--dangerously-skip-permissions  # 위험

🔴 MCP & 파이프라인

claude mcpMCP 서버 설정
/mcpMCP 기능 접근
git log --oneline | claude -p "요약"
cat error.log | claude -p "원인 찾기"

🔵 커스텀 명령어

.claude/commands/*.md → /debug /test /deploy 
claude --allowedTools "Bash(git:*)" "Write" \
  --disallowedTools "Bash(rm:*)"
claude --add-dir ../frontend ../backend

🟣 자동화 & 스크립팅

claude -p "analyze" --output-format json > a.json
SID=$(claude -p "start" --output-format json | jq -r '.session_id')
claude -r "$SID" "continue"
claude -p "s1" | claude -p "s2"

⚫ CI/CD·Git 연동

git diff HEAD~1 | claude -p "보안 리뷰" > r.md
claude -p "커버리지 분석" --output-format json | jq '.coverage_percentage'
docker logs c | claude -p "에러 찾기"

⚪ 성능 최적화

  • /clear 작업마다 자주 사용
  • --max-turns로 컨텍스트 제한
  • /compact "핵심만"
  • claude -p a & claude -p b & wait

🔘 엔터프라이즈

claude --production-mode --security-enabled \
  --audit-logging --max-turns 10
claude --disallowedTools "Bash(rm:*)" "Bash(sudo:*)" \
  --audit-mode --no-external-calls

💡 실무 모범 사례

성능/보안

  • 작업 전환마다 /clear, --max-turns로 폭주 방지
  • --dangerously-skip-permissions 지양, --disallowedTools 상시 적용
  • 도구 권한 주기 점검, 최신 버전 유지

워크플로우

  • 반복 작업 → .claude/commands/ 커스텀화
  • 자동화 → --output-format json, 세션 ID 활용

🧭 레벨별 학습 가이드

초급: 기본 명령어 → /help → 작업 간 /clear
중급: 도구 권한 → JSON 자동화 → MCP → 커스텀 명령어
고급: CI/CD 자동화 → 팀 협업 → 성능 모니터링 → 보안 정책

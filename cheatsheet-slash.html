⌨️ Claude Code 슬래시 명령어 & 플러그인 치트시트

내장 슬래시 명령어 전체 + 플러그인 설치 문법 + 가장 많이 쓰는 플러그인 5선, 공식 문서 기준
공식 문서 웹 조사 기준 최종 확인: 2026-08-12
출력 권장: A3 가로, 여백 최소, 배경 그래픽 인쇄 켜기

💬 세션 & 대화 관리

/rename [name]세션 이름 변경
/branch [name]대화 분기
/fork [prompt]새 백그라운드 세션으로 복사
/export [filename]대화 내보내기

🧩 플러그인 명령어 문법

/plugin                       # Discover/Installed/
                               # Marketplaces/Errors 탭

/plugin marketplace add owner/repo | url | 경로
/plugin marketplace list / update <name> / remove <name>

/plugin install <name>@<marketplace>
/plugin uninstall / enable / disable <name>@<marketplace>
/plugin list [--enabled|--disabled]

/reload-plugins [--force]     # 변경사항 즉시 적용

📦 플러그인 스코프 & 관리

User내 계정, 모든 프로젝트에 설치
Project.claude/settings.json에 기록, 협업자 공유
Local이 저장소에서 나만(.local.json)
스킬은 plugin-name:command 형태로 네임스페이스 (예: /commit-commands:commit)
⚠️ 설치 요약에 "Run /reload-plugins to activate." 표시되면 반드시 실행

⭐ 가장 많이 쓰는 플러그인 TOP 5

1. Frontend Design (공식) — 디자인 토큰·레이아웃 추론으로 UI 품질 향상, 공식 마켓 설치 1위
/plugin install frontend-design@claude-plugins-official
2. Superpowers (커뮤니티) — 브레인스토밍·서브에이전트 개발·TDD 등 워크플로우 모음
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace
3. Context7 — 최신 라이브러리 문서를 온디맨드로 조회
/plugin marketplace add upstash/context7
/plugin install context7@context7-marketplace
4. Claude Mem — 세션 간 영구 메모리 추가
npx claude-mem install (플러그인 시스템 아닌 별도 설치)
5. Caveman — 토큰 절약형 축약 응답 모드
/plugin marketplace add JuliusBrussee/caveman
/plugin install caveman@caveman
⚠️ Anthropic은 설치 통계를 공개하지 않음 — 순위는 ClaudeMarketplaces 등 커뮤니티 집계 기준. 서드파티 플러그인은 설치 전 신뢰 여부 직접 확인 필요

개발 워크플로우

  • security-guidance — 변경마다 자동 보안 리뷰
  • commit-commands — 커밋·푸시·PR 생성 스킬
  • pr-review-toolkit — PR 리뷰 전용 에이전트
  • agent-sdk-dev, plugin-dev — SDK·플러그인 개발 도구

💡 플러그인 실무 팁

  • 설치 전 출처 신뢰도 확인 — Anthropic은 서드파티 플러그인 내용을 검증하지 않음
  • 설치 화면의 Context cost로 매 턴 추가되는 토큰 비용 확인
  • 2주·10세션 이상 미사용 플러그인은 Installed 탭에서 정리
  • 스크립팅 설치: claude plugin install <name>@<marketplace> --scope project

🧭 언제 슬래시 vs 플러그인

내장 슬래시 명령어 → 세션·모델·진단 등 Claude Code 자체 기능 제어
플러그인 → 스킬·에이전트·MCP·Hooks를 패키지로 확장, 설치 후 plugin:command 형태로 사용

🛠 커스텀 슬래시 명령어 만들기

.claude/commands/*.md 에 정의
  • frontmatter: name, description, aliases
  • 본문에 $ARGUMENTS 로 인자 전달
  • 예: .claude/commands/deploy.md → /deploy 로 호출

🎯 실전 조합 예시

  • 새 기능 개발: /plan → 승인 → 구현 → /code-review → /security-review
  • 디버깅 막힐 때: /rewind 로 되돌린 뒤 원인 파악 후 재시도
  • PR 마무리: /diff 로 검토 → 커밋 → /release-notes
